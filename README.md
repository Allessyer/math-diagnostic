# Математический компас

Адаптивная русскоязычная диагностика: 10 базовых и 5 уточняющих заданий, радар навыков, локальный отчёт и необязательная анонимная обратная связь.

## Запуск

`python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Проверка логики: `npm test`.

## Механика

После десяти базовых заданий система выбирает по одному уточняющему заданию для каждого раздела: на предпосылки при результате ниже 50%, иначе усложнённое. Правильные ответы получают вес сложности, итог нормализуется до 100. Прогресс хранится только в `localStorage`; отчёт скачивается в JSON или печатается в PDF. Банк вопросов находится в `questions.js`, расчёты — в `engine.js`.

## Бесплатная база отзывов

1. Создайте проект на [Supabase](https://supabase.com/).
2. В SQL Editor выполните `supabase/schema.sql`.
3. В Project Settings → API скопируйте Project URL и publishable/anon key в `config.js`. Никогда не помещайте туда `service_role` key.
4. Читайте и экспортируйте отзывы через Table Editor → `feedback`.

Политика RLS разрешает публичному сайту только добавлять отзывы: читать, менять или удалять строки посетители не могут. Пустой комментарий не отправляется. Сохраняются текст, время, число вопросов, баллы по темам и версия сайта — без имени и полных ответов ученика. При широком публичном запуске рекомендуется добавить CAPTCHA и ограничение частоты через Edge Function.
