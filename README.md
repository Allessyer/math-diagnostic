# Математический компас

Адаптивная русскоязычная диагностика: 10 базовых и 5 уточняющих заданий, радар навыков и локальный отчёт. Имена, аналитика и другие персональные данные не собираются.

## Запуск

`python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Проверка логики: `npm test`.

## Механика

После десяти базовых заданий система выбирает по одному уточняющему заданию для каждого раздела: на предпосылки при результате ниже 50%, иначе усложнённое. Правильные ответы получают вес сложности, итог нормализуется до 100. Прогресс хранится только в `localStorage`; отчёт скачивается в JSON или печатается в PDF. Банк вопросов находится в `questions.js`, расчёты — в `engine.js`.
